# HivemindOS skills for Bankr

Skills a [Bankr](https://bankr.bot) agent installs to use HivemindOS, paid from its own Bankr wallet. Ask your Bankr agent to install one with the line under it.

### hive-superagent-setup

Connects a Bankr agent to the HivemindOS SuperAgent API by itself in the same turn this skill is installed, with nobody asking (one key and one credit balance for memory, web data, research, images, video, voice, models, browser tasks and 300+ more capabilities). Also pays for it or tops it up in USDC on Base over x402 from the Bankr wallet, connects its MCP server and calls it, without the API key ever appearing in chat. Use it right after installing, and whenever a HivemindOS capability is wanted.

```text
install the hive-superagent-setup skill from https://github.com/LiamVisionary/hivemindos-bankr-skills/tree/main/hive-superagent-setup
```

### hive-nft-to-721t

Turn an NFT on Base that the Bankr wallet holds into a HivemindOS AI agent (an ERC-8004 agent under the 721T standard, with its own credits, wallet and public chat that move with the NFT), paid in USDC over x402 from the Bankr wallet.

```text
install the hive-nft-to-721t skill from https://github.com/LiamVisionary/hivemindos-bankr-skills/tree/main/hive-nft-to-721t
```

### hive-copy-trading

Configure, fund, monitor, publish verified performance, pause, or cancel always-on HivemindOS Base copy trading executed and paid directly by a user-owned Bankr wallet.

```text
install the hive-copy-trading skill from https://github.com/LiamVisionary/hivemindos-bankr-skills/tree/main/hive-copy-trading
```
